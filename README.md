# Python Calculator

## About the Project
This is a simple calculator developed using Python. It performs basic mathematical operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero error handling

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
py calculator.py
```
